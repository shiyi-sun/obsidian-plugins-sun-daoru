# Daoru

[English](README.md) | 简体中文

Daoru 是一个只支持桌面端的 Obsidian 插件，用来把 Microsoft Word 文档（`.docx` / `.docm`）导入成 Markdown 笔记。它会转换文档结构，把内嵌图片存进你的库，并在每次导入后列出丢失或降级的内容，让你清楚知道有哪些内容没能进入笔记。

需要 Obsidian 1.14.4 或更高版本。插件界面目前只有中文；在 Obsidian 里显示的名称是 **Daoru**，插件 ID 是 `sun-daoru`。

## 功能

- 导入单个文档、多个文档，或整个文件夹。
- 文件夹导入保留源文件夹名和内部层级。
- 可以新建笔记，也可以把内容插入当前打开的笔记。
- 保留标题、列表、表格、链接、图片和图片替代文字。
- 简单表格转成 Markdown 表格，复杂表格保留为 HTML。
- 图片可以放在 Obsidian 设置的附件位置、笔记旁边，或固定的文件夹。
- 每个文件都有导入结果，逐项列出丢失和降级的内容。
- 额外做一次文字核对，标出在生成笔记里找不到的段落。
- 可以选择写入 `source`、`imported` 来源信息，以及为「一个文件标题 + 多级章节」的文档整理标题层级。

## 使用

### 导入文档

1. 点击功能区里的导入图标，或在命令面板运行 `导入 Word 文档…`。
2. 选择一个或多个 `.docx` / `.docm` 文件。
3. 选择新建笔记还是插入当前笔记，指定目标文件夹，然后开始导入。
4. 查看导入结果。

一次导入多个文件时只能新建笔记。插入当前笔记要求只选一个文件，并且当前有处于编辑视图的 Markdown 笔记。

### 导入文件夹

点击功能区里的文件夹导入图标，或在命令面板运行 `导入 Word 文件夹…`。Daoru 会在目标文件夹下重建所选文件夹及其子文件夹，再导入找到的所有 Word 文件。

空文件夹、非 Word 文件、隐藏项（`~$` 临时文件或以点开头的名称）、`node_modules` 和 `__MACOSX` 会跳过。文件夹导入始终新建笔记。

## 会保留什么

| Word 里的内容 | 笔记里的结果 |
| --- | --- |
| 标题 | Markdown 标题 |
| 项目符号和编号列表 | Markdown 列表 |
| 简单表格 | Markdown 表格 |
| 复杂表格 | HTML 表格，包括合并单元格和嵌套内容 |
| 外部链接 | Markdown 链接 |
| 文档内跳转 | 去掉链接，保留链接文字 |
| 图片 | 提取为附件；Word 里的替代文字写成图片 alt |
| 加粗、斜体、下划线、删除线、上标、下标 | 对应的 Markdown 或 HTML 行内格式 |
| 文本框里的文字 | 能读到时保留；读不到时在导入结果里列出 |

## 不会导入什么

- 页面版式和字符格式：字体、字号、颜色、对齐、段落间距、缩进、页边距。
- 页眉和页脚。
- 批注框里的内容。被批注的正文会保留。
- 未接受修订里被删掉的文字。修订中插入的文字会保留。
- Word 公式（OMML）。不会转换；正文里每处公式会在原位置留下「【公式未导入】」标记，并在导入结果里计数。
- 图表、SmartArt 和 Excel 等嵌入的 OLE 对象。
- 以「链接到文件」方式插入的图片，因为图片本体不在文档里。
- 页码、目录、交叉引用等域的计算结果，部分域可能不完整。
- 书签、目录条目、交叉引用等文档内跳转。看得见的文字会保留，但链接不再可用。

EMF、WMF、TIFF 等 Obsidian 无法预览的图片会照常保存，并在正文里改成附件链接，原文件不会丢。

## 导入结果

每次导入结束都会按文件显示结果：

- **丢失**：笔记里没有对应内容。
- **降级**：内容以缩减后的形式保留，例如域结果或无法预览的图片。
- **说明**：值得知道的信息，例如重复引用了同一张图片。

丢失项包括批注、页眉页脚、公式、图表与嵌入对象、链接到文件的图片、文档内跳转、读不到的文本框文字，以及修订里被删除的文字。每一项会给出数量和能取到的内容示例。正文里的公式还会在对应位置标出，搜索「公式未导入」可以逐个定位。

Daoru 还会把文档 XML 里的文字与生成的 Markdown 做一次核对，报告找不到的段落，用来发现已知类别之外的丢失。如果出现这条提示，请保留原文档，方便排查。

## 附件

默认情况下，附件跟随 Obsidian「文件与链接」里的附件设置。可以开启「按文档建附件子文件夹」，把图片存到笔记同目录的 `<笔记名>-附件/`，或改用相对库根目录的固定文件夹。

开启按文档建附件子文件夹时，插入当前笔记会把附件放在当前笔记旁边。

## 设置

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 默认导入方式 | 新建笔记 | 新建笔记或插入当前笔记。批量导入和文件夹导入始终新建笔记。 |
| 按文档建附件子文件夹 | 关闭 | 图片存到笔记同目录的 `<笔记名>-附件/`。 |
| 附件位置 | 跟随 Obsidian 设置 | 关闭按文档建子文件夹后生效。可以跟随「文件与链接」设置，或使用固定文件夹。 |
| 附件文件夹 | `附件/导入` | 固定文件夹路径，相对于库根目录。不存在时会自动创建。 |
| 整理标题层级 | 关闭 | 文档使用「文件标题 / Title」样式时，把其余标题整体下移一级。 |
| 新建笔记时写入来源信息 | 关闭 | 在开头写入 `source`（原文件名或相对路径）和 `imported`（导入日期）。 |
| 导入后打开笔记 | 开启 | 导入结束后打开第一篇成功新建的笔记。 |

导入对话框里还可以临时选择目标文件夹，以及这一批文件是否写入来源信息。

## 安装

### 使用发布包

1. 从 [GitHub Releases](https://github.com/shiyi-sun/obsidian-plugins-sun-daoru/releases) 或 [AtomGit Releases](https://atomgit.com/shiyi-sun/obsidian-plugins-sun-daoru/releases) 下载最新的插件包。
2. 解压后是一个 `sun-daoru/` 文件夹，里面有 `main.js`、`manifest.json` 和 `styles.css`。
3. 把这个文件夹放到 `<库根目录>/.obsidian/plugins/sun-daoru/`。
4. 重新加载 Obsidian，然后在「设置 → 第三方插件」里启用 **Daoru**。

升级已有安装时，保留 `sun-daoru` 这个文件夹名，替换里面的三个文件即可。

### 从源码构建

```bash
git clone https://github.com/shiyi-sun/obsidian-plugins-sun-daoru.git
cd obsidian-plugins-sun-daoru
npm install
npm run build
```

把生成或已有的 `main.js`、`manifest.json` 和 `styles.css` 复制到 `<库根目录>/.obsidian/plugins/sun-daoru/`。

## 环境要求与限制

- Obsidian 1.14.4 或更高版本，只支持桌面端。
- 支持 `.docx` 和 `.docm`。旧版 `.doc` 需要先另存为 `.docx`。
- 加密或带密码的文档无法读取。
- 插件界面目前只有中文。
- 所有转换都在本地完成，文档不会上传到任何地方。
